# About this Bench

The FAIR Knowledge Object Bench is a place to explore how knowledge can be packaged so that people and computers can find it, understand it, and use it. It is designed for learning: you can see what an object contains and how information about that object changes what you are able to do with it.

## What is a Knowledge Object?

A Knowledge Object brings computable knowledge together with the materials needed to describe and use it. Those materials may include a specification of what the knowledge does, an implementation that carries it out, supporting documents, and metadata. A Knowledge Assembly is also a Knowledge Object. It coordinates the work of other Knowledge Objects to produce a result.

## Why does metadata matter?

Metadata is information *about* an object. It can tell you what the object is, how to locate and obtain it, what its inputs and outputs mean, what it is based on, and where its use is limited.

## What can you do here?

- Explore an object's contents and metadata.
- Try the metadata exercises and see what changes.
- Run compatible objects and examine their results.
- Download an object or your working version.

The Bench is a general-purpose teaching environment. The objects available in it may change; the questions it helps you ask remain the same. The Knowledge Objects and Assemblies in the Bench are educational examples only and not for real-world use of any kind.
